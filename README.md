# Polars JS DataFrame CSV viewer

Local viewer for inspecting and comparing Polars DataFrames exported from Weaver.
Generated CSV files in this directory are ignored by Git.

## Get Dataframe CSV


```ts
  // CSV's should be downloaded into /input folder
  dataframe.sink(<input_folder_path>).collect()
```

Run the code path that produces the DataFrame.

## Start the viewer

First install nodejs-polars running:
```bash
  npm install
```

From the repository root:

```bash
node server.js
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Run a query

Open the Query tab, select the CSV files to load, and return a Polars DataFrame or LazyDataFrame:

```js
frames.meetings_frame
  .filter(pl.col('has_participation').eq(true))
  .select('meeting_id', 'scheduled_at');
```

The runner applies a 500-row result limit and a five-second timeout.
Queries execute trusted local JavaScript, so do not paste untrusted code.

## Features

- Automatic CSV discovery
- Side-by-side CSV comparison
- Independent column visibility controls
- Independent row keys for matching differently named columns
- Changed-cell and missing-row highlighting
- Differences-only filtering
- Search, column sorting, and synchronized scrolling
- Syntax-highlighted Polars query editor with result and execution-plan tables

## Technologies

- HTML and CSS
- Vanilla browser JavaScript
- Monaco Editor 0.56.0 loaded from a pinned CDN URL, with a textarea fallback when unavailable
- `nodejs-polars` declarations loaded from the local Weaver installation for IntelliSense
- Node.js local HTTP server and worker threads
- `nodejs-polars` 0.25.1, matching Weaver
- CSV files generated by Polars `sinkCSV`
